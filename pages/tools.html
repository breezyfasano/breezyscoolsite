Tools & Resources

HTML & CSS

  • HTML For People - If you're confused and don't remember how to start, or need an all around "how the heck do I do this" refresher, this is the resource for you. It mirrors a lot about what we talked about in class, and is a GREAT reference for everyone new to HTML & CSS.
  • MDN HTML Reference - beware of some jargon here, but overall an amazing place to see all HTML elements at your disposal. It's a great reference on what they do and how you can use them. It is organized based on how elements are used.
  • Interneting is Hard - a really great and linear tutorial on everything you need to know to make your own website! Expand on basic concepts you learned in class.
  • Jon Duckett's HTML & CSS Book - Somewhat outdated now, but not by much. An incredible resource to visually learn HTML & CSS basics.
  • 30 CSS Selectors You Must Memorize - A bit more advanced, but this is the concept that makes you a CSS power user. Selectors get unruly fast, so remember: beware specificity.
  • CSS Properties Reference - All CSS properties available to you. BEWARE - not all of these are supported in every browser!
  • caniuse - this website will tell you if the CSS property you are trying to use is supported by all web browsers. If not, it will tell you which browsers do and do not support it.

Organization & Structure

  • How to Structure Your Website Files - How to organize your files as your site grows! SUPER important

Utilities

  • WordHTML - Write long bits of text and/or content and have it converted to HTML for you
  • Photopea - Photoshop alternative, right in your browser. It ROCKS.
  • Tinypng - Make your images smaller and optimized for the web
